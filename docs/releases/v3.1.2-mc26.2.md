# Canvas Studio+ 3.1.2 — Minecraft 26.2

**made by SuprixZ**

Paintings can now occupy **1×1 up to 8×8 blocks**, including rectangular sizes. Use **Studio menu → Painting size**, then save and place your map at the wall area's lower-left corner. Artwork stays 128×128 and scales to the chosen wall size.

Sizes survive map pickup, saved-map editing, CSP project files and entity persistence. Older paintings default to 1×1. The complete wall area is checked for support, clearance and build permission. All Canvas Studio+ 3.1.0 features remain.

Use matching 3.1.2 client/server versions. Minecraft 26.2 only, NeoForge 26.2.x including betas. A separate Minecraft 26.3 build is provided.

Automated checks and published API/range audits gate release; **no interactive in-game testing was performed**. See attached VALIDATION.md and logs.
