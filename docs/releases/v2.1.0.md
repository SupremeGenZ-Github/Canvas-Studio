# Canvas Studio+ 2.1.0

**made by SuprixZ** — Minecraft Java **26.3**, NeoForge **26.3.x** including beta builds, Java **25**.

Adds Blank (painting only), Molder (one successful Get Item exchange) and Infinity (unlimited exchanges) canvases. Adds Molder/Infinity Quills, the matching shapeless canvas recipes, full 3x3 shaped quill upgrades, distinct assets and server permissions. Removes the feather canvas shortcut. Existing paintings, image tools and the offline vanilla item matcher are preserved.

Each successful request creates one plain item/block without requiring inventory ownership. Molder replaces the canvas; Infinity keeps it and adds/drops the reward. One-use server tokens reject duplicates and validate the held hand, stack, tier, drawing and item ID. Cancelled/failed/rejected requests do not consume canvases.

Install one Canvas Studio edition only; all clients and the server must use 2.1.0. Older Blank Canvas items still paint, with Get Item locked. Saving a painting converts any canvas into a map.

Automated checks passed, including a 56-build NeoForge binary API audit. **No interactive in-game tests performed.** See [validation](https://github.com/SupremeGenZ-Github/Canvas-Studio/blob/v2.1.0/VALIDATION.md) for exact scope and remaining checks.
