# Canvas Studio Lite 1.0.3

**- made by SuprixZ**

**Only available for NeoForge 26.3.0.51 (26.3.0.51-beta), Minecraft Java 26.3, Java 25.**

Painting edition without the item/block finder. Includes canvas/quill crafting, drawing, color palette, brush sizes, eraser, fill, undo, PNG/JPEG import, PNG export and named paintings for item frames. Includes the corrected Minecraft 26.3 advancement format and mouse button constants.

Install `canvas-studio-lite-26.3-nf51-1.0.3.jar` in `mods`. Install only one Canvas Studio edition. Servers and clients must use the same edition/version.

Existing image, packet, advancement and headless editor input checks passed. Interactive multiplayer gameplay was not tested. This release changes the previously built 1.0.3 display branding to Canvas Studio Lite; it does not change painting behavior.
