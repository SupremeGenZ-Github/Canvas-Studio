# Canvas Studio Lite 1.0.4

**- made by SuprixZ**

**Supports NeoForge 26.3.x (including beta builds) on Minecraft Java 26.3; Java 25 required.**

Painting edition without the item/block finder. Keeps all existing painting, drawing and image import/export features.

Removes the exact 26.3.0.51-beta restriction. API signatures were audited against all currently published NeoForge 26.3 builds, from 26.3.0.0-beta through 26.3.0.57-beta. Future 26.3 builds are accepted; future compatibility is not guaranteed before those builds exist. No interactive world/multiplayer version-matrix tests were run.

Install `canvas-studio-lite-26.3-1.0.4.jar`, replacing the previous edition JAR. Install only one edition, and use the same edition/version on server and clients.

This is a metadata compatibility update: class bytes and gameplay resources are unchanged from 1.0.3. The older release remains available with its original exact-version requirement.
