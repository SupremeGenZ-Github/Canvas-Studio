# Canvas Studio+ 2.1.1

**made by SuprixZ**

Renames Molder to Molten and replaces upgrade recipes:

- Molten Quill: Quill centered, four Iron Ingots in corners, four Gold Ingots on edge centers.
- Molten Canvas: shapeless Blank Canvas + Molten Quill + Compass.
- Infinity Quill: Molten Quill centered, four Echo Shards in corners, two Lapis Blocks left/right, two Diamond Blocks top/bottom.
- Infinity Canvas: shapeless Molten Canvas + Infinity Quill + Recovery Compass.

Old item IDs are retained so existing Molder items become Molten. Textures stay unchanged. Painting, import/export, one-use Molten and reusable Infinity exchange rules remain intact.

Minecraft 26.3, Java 25, NeoForge 26.3.x including betas. Future API compatibility is not guaranteed. Install one Canvas Studio edition and use matching client/server versions.

Automated verification and actual in-game test scope: [VALIDATION.md](https://github.com/SupremeGenZ-Github/Canvas-Studio/blob/v2.1.1/VALIDATION.md).
