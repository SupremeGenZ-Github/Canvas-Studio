# Canvas Studio+ v3.2.2 — Reopen & Edit

**made by SuprixZ**

Built on Material Frames v3.2.1. All eleven material-backed frames and Living Gallery features remain.

## Reopen, unlock and edit saved paintings (v3.2.2)

A saved or locked painting remains editable by its **owner or an administrator**. Place it on the wall, then **Shift-right-click it** to reopen. You can also hold the saved painting map in either hand and **Shift-right-click in the air**.

For locked paintings, the reopening menu offers:

- **Edit keeping locked:** change the artwork while retaining owner/admin protection.
- **Unlock & edit:** the server immediately makes the existing painting publicly editable and opens a fresh editor session. No new canvas or frame material is used.
- **Cancel:** leave the painting as it is.

Draw, import, resize or adjust animation, then choose **Save edited painting**. Wall edits update that same placed painting; no item frame or breaking/replacing is required. In **Studio menu → Display / access**, choose **Lock painting on save** or **Unlock painting on save**. Only the owner/admin can change access; public editors cannot take ownership or relock another player's art.

Unlocking preserves the painting's name, pixels, animation map IDs, wall dimensions, display layout and frame material. Keeping the same frame remains free; changing it uses v3.2.1's one-material rule. The server checks the bound hand/painting/revision/session and invalidates the old capability after a successful unlock. If persistence fails, the original item and lock stay intact.

## Compatibility and validation

Existing saved maps, placed paintings, animation sequences, frame IDs, CSP1–4 projects and CSA1 gallery data remain supported. No crafting recipes or item textures changed. Network protocol 8 requires matching v3.2.2 client/server editions.

The opening menu makes the existing owner-edit permission explicit, and adds an immediate server-authorized unlock operation. The native map artwork stays fixed; unlocking changes player access. Already saved items gain the new controls when reopened. New saves include a tooltip describing Shift-right-click editing.

Release gates: all 17 Java verification suites, packaged artifact checks, default/endpoint builds, published-family API/range audit, and fresh headless-server startup/save/stop. The new suite covers owner/admin access, relocking, immutable persistence/failure behavior, preserved art/display/map metadata, source reload, revision overflow, both hands/wall packet codecs and stale capabilities.

No interactive client rendering, live player inventory transactions, multiplayer lock workflows or actual placed-painting edit/save were tested. These remain preview releases; see the attached validation report and logs for executed results.

This download targets **Minecraft 26.2 / NeoForge 26.2.x**, including betas. The other Minecraft family requires its separate JAR. Future API changes require renewed verification.
