# Canvas Studio 2.0.0

**- made by SuprixZ**

**Only available for NeoForge 26.3.0.51 (26.3.0.51-beta), Minecraft Java 26.3, Java 25.**

Full edition with the item/block finder, plus all Lite painting features. Switch to Get Item mode, draw an item or block, and use Find Item / Block. Compare up to three matches and exchange one Blank Canvas for one plain chosen item/block.

Offline approximate shape/color matching uses 1,198 supported vanilla inventory candidates. No API key or cloud recognition service is required. Similarity is a visual comparison score, not a confidence probability; rough drawings or unsupported special models may not match well.

Install `canvas-studio-26.3-nf51-2.0.0.jar` in `mods`, replacing earlier Canvas Studio/Canvas Studio+ JARs. Do not install Lite alongside it. Servers and clients must use this same full edition/version.

Build, headless drawing, codec, asset matching and exchange validation checks passed. Actual in-game inventory exchange and multiplayer gameplay remain untested. This release rebrands the earlier Canvas Studio+ 2.0.0 as Canvas Studio.
