# Canvas Studio+ 2.1.2 for Minecraft 26.2

**made by SuprixZ**

Separate port for **Minecraft 26.2**, **NeoForge 26.2.0.88**, **Java 25**. Keeps all Molten/Infinity crafting recipes, textures, painting/import/export, saved paintings, matching and server reward protections. Uses the TinyFD file picker provided by 26.2 and adapts recipe-book unlock data, resource selector and server drop API.

Use `canvas-studio-plus-26.2-2.1.2.jar`. Remove other Canvas Studio JARs. Install the same port on client and server. The original 26.3 downloads remain available.

Clean build and automated checks gate publication; logs and validation are attached. No interactive in-game testing performed.
