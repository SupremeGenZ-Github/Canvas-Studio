# Compatibility

Minecraft 26.3, Java 25, NeoForge `[26.3-alpha,26.4-alpha)`, FML `[12,)`. Install matching protocol-4 builds on client/server. The 26.2 port is separate. See VALIDATION.md and release audit for executed checks. Unknown future API changes are not guaranteed compatible. Lite is unchanged. Existing map saves and legacy item IDs are preserved.
